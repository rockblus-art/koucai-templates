## 快速上手（示例 3 条）

### 场景：老板问你进度，你其实没做完（`templates/workplace-report/`）

> 直接版（诚实 + 补方案）："目前完成了 X 和 Y，还差 Z，Z 卡在 A 环节，我预计周三前能完成。如果需要提前，建议把 B 部分先给到对方。"
> 要点：**先报完成项 → 再报卡点 → 给时间节点 → 给可选方案**。永远不要只说"还在做"。

### 场景：饭局被劝酒，你不太能喝（`templates/toast`）

> 柔和拒绝版："我敬您一杯，以茶代酒。祝您 XX（具体祝福，别只说'身体健康'）。"
> 要点：**祝福要具体**，动作要满（起身、双手、眼神），拒绝一次就守住。

### 场景：客户说"再考虑考虑"（`templates/sales-followup/`）

> 不追问版："没问题，您慢慢考虑。方便的话我周四再跟您同步一次 XX 的最新情况——您看是电话方便还是发您文字？"
> 要点：**给台阶 + 约定下次触点 + 把主动权变成选择题**。"再考虑"不是拒绝，是没有下一步。

## 30 天训练路线（`method/`）

1. **第 1 周**：对着家人/同事 2–3 人围观，每天 1 分钟自我介绍
2. **第 2 周**：部门小会主动发言（10 人以内），练开场"固定件"
3. **第 3 周**：模拟路演/汇报（20 人以上），忘词不硬背、练接话反应
4. **第 4 周**：VR 实景模拟高压场景（面试、汇报、当众演讲），失败成本归零
