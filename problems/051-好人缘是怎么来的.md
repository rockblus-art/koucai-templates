# 好人缘是怎么来的

怎么样拥有好人缘，这里有9个小技巧。
第一，不要轻易收人家礼物，因为你懂得迟早要还的。
第二，求人家办事，或者帮人家办事，不要轻易的许诺，可是一旦承诺一定要及时的清账。
第三，不要去比较，因为比上不足比下有余，这是常态，你要么接受，要么努力之后再接受。
第四，不要给别人过高的期望，因为9次好人加1次坏人等于不受尊敬的坏人，而9次坏人加一次好人等于受尊敬的好人。
